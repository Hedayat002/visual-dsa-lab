Problem input

Find the nth character in 123456789101112...
1 ≤ n ≤ 10⁹
Current remaining n11

Initial state

length1
count9
start1
Each loop skips one complete digit-length group, if the target lies beyond it.

Core condition

while n > length × count
Group digit total = length × count. Skip it only when the remaining target is greater than that total.
num = start + (n−1)//length
idx = (n−1)%length

Variable meanings

length — digits per number
count — numbers in this group
start — first number in group
num — target number
idx — digit index within num

Key idea

Digits ko group-wise skip karo: 1-digit numbers contribute 9 digits, 2-digit numbers contribute 180 digits, and so on. Correct group milne par arithmetic se number aur digit index nikaal lo—full string build nahi karni.

Correctness

Skipping removes exactly the digits before the target group. Division identifies the target number; modulo identifies its character index.

Complexity & takeaway

Time: O(log n), groups grow by ×10.
Space: O(1), no concatenated string is stored.

Submitted Python code

class Solution:    def nthCharacter(self, n):        length = 1        count = 9        start = 1        while n > length * count:            n -= length * count            length += 1            count *= 10            start *= 10        num = start + (n - 1) // length        idx = (n - 1) % length        return str(num)[idx]

Important observation

The first group has 9 × 1 = 9 digits. The second has 90 × 2 = 180 digits. Each next group has ten times as many numbers and one extra digit per number.
