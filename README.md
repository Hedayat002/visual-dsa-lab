# Interactive DSA Visual Dry Runs

This repository contains interactive HTML visualizations of Data Structures and Algorithms (DSA) problems to help understand algorithms through step-by-step execution, visual representations, and live dry runs.

## 🚀 How to Use the HTML Visualizations

You can use any HTML visualization in **two ways**.

### Method 1: Copy the Code and Run It Online

1. Open the HTML file in this repository.
2. View the complete source code.
3. Copy the entire HTML code.
4. Open any online HTML compiler or HTML code editor that supports HTML, CSS, and JavaScript.
5. Paste the copied code into the editor.
6. Run or preview the code to start using the interactive visualization.

This method is useful when you want to run the visualization online without downloading the file.

### Method 2: Download and Open Directly in Your Browser

1. Open the required HTML file in the repository.
2. Download the file to your computer.
3. Locate the downloaded `.html` file.
4. Double-click the file or right-click it and select **Open with → Chrome** (or another modern browser).
5. Start exploring the interactive visualization.

**Note:** The HTML files are self-contained and are designed to work locally without a server or external libraries.

## 🎮 Interactive Features

Depending on the visualization, you can use features such as:

- **Play / Start:** Automatically execute the dry run.
- **Pause:** Stop automatic execution.
- **Previous / Next:** Move backward or forward through individual steps.
- **Reset:** Restart the visualization.
- **Speed Control:** Adjust the playback speed.
- **Live Visualization:** Observe changes in arrays, pointers, variables, data structures, and intermediate results.
- **Code Highlighting:** Follow the relevant code operation during execution.
- **Execution Trace:** Inspect the sequence of operations and state changes.

The available controls may vary depending on the algorithm being visualized.

## 📚 Topics Covered

This repository can include interactive visualizations for topics such as:

- Arrays and Strings
- Sliding Window
- Two Pointers
- Searching and Sorting
- Binary Search
- Recursion and Backtracking
- Linked Lists
- Stacks and Queues
- Trees and Binary Search Trees
- Graphs and Traversals
- Dynamic Programming
- Greedy Algorithms
- Hashing and other DSA concepts

## 🎯 Purpose

The goal of this repository is to make DSA learning more visual and practical. Instead of only reading a solution, you can observe how an algorithm executes, how variables change, why decisions are made, and how the final answer is obtained.

Each interactive visualization is intended to support algorithm understanding, debugging, interview preparation, and daily coding practice.

## 💻 Requirements

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- An internet connection is needed to access the GitHub repository or an online HTML editor.
- Once a self-contained HTML file is downloaded, it can generally be opened and used offline.
