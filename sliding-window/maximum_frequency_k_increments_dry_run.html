Maximum Frequency with K Increments

Use at most k increment operations to make the frequency of any element as large as possible.

💡 Algorithm (Sliding Window)

  1. 1Sort the array in ascending order.
  2. 2Move right across the sorted array and add each value to window_sum.
  3. 3Calculate the cost to raise the whole window to arr[right].
  4. 4If cost exceeds k, remove left values until the window is valid.
  5. 5Update res with the current window size.
  6. 6The largest valid window is the maximum frequency.

‹/› Code (Python)

class Solution:    def maxFrequency(self, arr, k):        arr.sort()        window_sum = 0        left = 0        res = 1        for right in range(len(arr)):            window_sum += arr[right]            while arr[right] * (right-left+1) - window_sum > k:                window_sum -= arr[left]                left += 1            res = max(res, right-left+1)        return res
