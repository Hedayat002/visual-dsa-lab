Python code trace

Highlighted line matches the current operation.

arr.sort() window_sum = 0 left = 0 res = 1 for right in range(len(arr)): window_sum += arr[right] while arr[right] * (right-left+1) - window_sum > k: window_sum -= arr[left] left += 1 res = max(res, right-left+1) return res

Why it works

After sorting, arr[right] is the largest element in the current window. Only increments are allowed, so raising all window elements to this target is the cheapest way to make them equal. If the cost exceeds k, remove the leftmost value until valid.

Boundary idea: when k = 0, only already-equal values can share a valid window.

Key takeaway

1. Sorting makes the target the rightmost value.

2. The formula calculates total increments needed.

3. Shrink only while cost > k.

4. The largest valid window size is the answer.
